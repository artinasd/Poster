# ArtiQ VPN - UI Recreation

High-fidelity, pixel-perfect UI recreation of the ArtiQ VPN dashboard.

## Tech Stack
* HTML5
* Tailwind CSS (via CDN for layout utilities)
* Vanilla CSS (Custom properties, Glassmorphism, Glow systems, Animations)

## Architecture
* `variables.css`: Design tokens (colors, gradients, shadows, fonts).
* `base.css`: Resets, typography defaults, and background rendering.
* `layout.css`: Grid systems and container boundaries.
* `components.css`: Reusable UI systems (Glass panels, neon glows, badges).
* `animations.css`: Subtle premium animations (breathing glows, floating).
* `responsive.css`: Media query adjustments.
